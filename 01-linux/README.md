# Linux Administration & Automation

This section contains hands-on Linux administration, troubleshooting,
system monitoring, and Bash automation exercises.

## Topics Covered

- Linux filesystem
- File and directory management
- Permissions and ownership
- Users and groups
- Processes
- Services
- Package management
- Disk management
- Memory management
- Networking
- SSH
- Logs
- Bash scripting
- System monitoring

## Scripts

| Script | Purpose |
|---|---|
| `system-info.sh` | Displays system information |
| `disk-usage.sh` | Checks disk usage |
| `memory-check.sh` | Checks memory usage |
| `backup.sh` | Creates a backup |

## Environment

- Kali Linux / Debian-based Linux
- Bash
- Git

## Learning Goal

Build practical Linux administration and automation skills required
for DevOps and SRE roles.
